OPEN THE SITE
Open index.html. The top navigation is linked across the eight exported Stitch screens in the screens folder. The root index is the Home screen. Home uses a five-photo hero carousel from stitch-export\stitch_kenyan_safari_lodge_website\stitch_kenyan_safari_lodge_website\IMAGES. Images fill the hero with object-fit: cover and advance every five seconds.

FONTS
Playfair Display is loaded for headings as the requested more formal display typeface. Plus Jakarta Sans remains the body font from the Stitch export. Both Google Fonts and Stitch-hosted generated images require an internet connection.
